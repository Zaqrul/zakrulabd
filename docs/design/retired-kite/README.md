# Retired: Kite as the Aegis wing

Kite as a shot-catching escort (`space3-aegis.ts`) was dropped because it was the same idea as Space 2's Kite and Cover (a ship beside the player that shields it). Codex's ORB rescue-escort art (`space3-kite-art.ts`) and the behaviour tests are kept here, renamed `.txt` so they are not built. Halo and Kite stay in the story (the relief corridor, the evacuation lane); in play, the wingman is the new recruit, Lumen (`space3-recruit.ts`). The art could return for a Halo cameo.
